## Scope and status meanings

All **242 source-note groups**, covering **1,953 contiguous source lines**, have one primary family and an explicit disposition. The **45 named families** group overlaps; they are not tasks, priorities, or estimates. Every row links the immutable original note, preserving its complete examples and secondary topics. No source note was deleted or edited.

- **Completed (scoped):** the specific request has code and recorded operational evidence; stated follow-up remains separate.
- **Superseded target:** the named infrastructure was retired; preserve the historical request without reintroducing its old commands. This does not add a permanent roadmap scope exclusion.
- **Outstanding (code):** inspected code supports a specific unimplemented request. It is not approval to build it.
- **Partial:** some relevant behavior exists; the rest is explicitly unverified or incomplete.
- **Reference:** reference material retained for future evaluation, with no implementation commitment.
- **Unresolved:** this bounded pass cannot establish current implementation/completion. This is not a claim of absence, a validated bug, or a rejection. The row/family identifies the next check.
