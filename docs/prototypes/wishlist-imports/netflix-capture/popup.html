For testing only

The file this saves won't add Netflix titles to GoodWatch yet. This experiment doesn't record whether a title is a movie or a show, and GoodWatch can't match Netflix titles yet. If you upload the file, its titles show as not matched.

How to capture

  1. In this tab, open My List on netflix.com, with the profile you want.
  2. Choose Start capture.
  3. Scroll My List slowly to the end yourself. This popup closes when you click the page. The capture keeps running.
  4. Open this popup again and choose Stop and save file.
