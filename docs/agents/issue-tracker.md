# Issue tracker: GitHub

Track issues and specs in alp82/goodwatch-monorepo using gh.

Read the full issue and comments before working.
Use --body-file for multiline issue bodies.
Use native GitHub blocking dependencies where supported;
otherwise list blocking issues in the issue body.

When a skill says to publish a ticket, create a GitHub issue.
Do not publish until the ticket breakdown is approved.

PRs as a request surface: no.
