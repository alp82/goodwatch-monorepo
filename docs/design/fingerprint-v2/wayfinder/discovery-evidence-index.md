# Discovery and search evidence index

This is a read-only index of existing evidence for the V2 benchmark/prototype program, recorded October 19, 2026. No experiment, paid request or production check was run to write it. Historical observations below retain their original date and scope; prices are not current quotes. Use the linked manifests, captured outputs and dated log entries before treating a summary as a measurement.

## Start here: distinguish the three jobs

| Job | Existing evidence | What it does not establish |
|---|---|---|

Per-title generation/repair/embedding costs, per-uncached-query interpretation costs and CPU/index/retrieval costs need separate ledgers and amortization. “No new paid calls” in arena reports means **beyond the existing Jev reading**, not a free complete search. Full-payload title generation and scores-only classification also have different output coverage.

## Title knowledge, scales and output coverage: existing benchmark bridge

- **Measured report, September 17:** [Jev scoring experiment](../../../benchmarks/fingerprint/jev/README.md) compared 10 titles × 74 V1 traits, including ten- and six-level scoring ladders, presence gating, title-blind input, batch sizes and throughput. Its synopsis-only design disagreed substantially with the owner-reviewed Qwen reference, especially on craft absent from the synopsis. Removing the title did not worsen agreement. This supports a limitation of **that input/design**, not proof that every Jev version or enriched-state design can never know titles.
- Historical reported costs per 1,000 titles: Jev ten-level scores-only $0.79, six-level scores-only $0.55; Qwen3.8 Flash full output $0.85 and Qwen3.7 Flash full output $0.34. Reported latencies and batch settings are in the same table. These are dated, scope-unequal observations, not current provider comparisons. The ten-title Qwen reference is not ground truth; agreement alone cannot select a V2 design.
- **Traceable tools:** [prepare.py](../../../../goodwatch-flows/windmill/f/dna/prototype_comparison/prepare.py), [run.py](../../../../goodwatch-flows/windmill/f/dna/prototype_comparison/run.py), [jev_run.py](../../../../goodwatch-flows/windmill/f/dna/prototype_comparison/jev_run.py), [jev_report.py](../../../../goodwatch-flows/windmill/f/dna/prototype_comparison/jev_report.py), and the runner README above. The existence of a runner is not authorization to execute it or evidence that every stage ran. The Jev report notes private/raw-capture and branch requirements.
- **Cost/repeat evidence:** [Qwen repeatability and accounting](../../../benchmarks/fingerprint/poc/repeat-cost/repeatability.md), [embedding-cost report](../../../benchmarks/fingerprint/poc/repeat-cost/embedding-cost.md). Separate reconciled charges, unknown-call allowances, estimates and bounds; missing metadata is not zero spend.
- **Whole-output acceptance:** [acceptance report](../../../benchmarks/fingerprint/acceptance/README.md) and [highlight-validation followup](../../../benchmarks/fingerprint/acceptance/followups/validate-highlights.md). Earlier acceptance found invalid `highlight_keys` despite parseable generation. Read the followup rather than treating the initial report's retained invalid records as current production state.
- **Still unrun for V2:** whether Jev or alternatives can produce calibrated V2 assessments given equal evidence; whether coarse ordinal/presence categories outperform universal 0–10; and how a classification-only provider composes with an essence/highlight/companion-output generator. The historical Jev experiment expressly excluded essence prose and tags. Search's probability questions and ranking grades do not validate title-level measurement scales.

## Preserve the component experiments, not only the winner

The following reports link their lists, score files, diagnostic probes, complexity counts and rejected alternatives. Several begin with historical assistant-status text such as “not written”; their actual files are now preserved. Their provisional recommendations precede later pooling/grading and should not override the final log.

| Branch report | Reusable lesson |
|---|---|
| [Text](../../../prototypes/search-arena/results/simplify/text/REPORT.md) | Spell correction, negation, era, facets and multilingual coverage. Narrow literal retrieval can lose a requested conjunction; absent labels limit exclusions. |
| [Entity](../../../prototypes/search-arena/results/simplify/entity/REPORT.md) | Person/studio resolution, ambiguity and credit classes. Cached embedding timings omit a new intent encode. |
| [Reference](../../../prototypes/search-arena/results/simplify/reference/REPORT.md) | “Like X,” people and studios as seed profiles; own-title bounds and reference modifications. Similarity needs desired-aspect interpretation. |
| [Fusion](../../../prototypes/search-arena/results/simplify/fusion/REPORT.md) | Candidate depth, shared secondary weights and fitting. Condensed scores can hide unjudged results; in-sample fitting is not confirmation. |
| [Combined module](../../../prototypes/search-arena/results/simplify/combo/REPORT.md) | Interactions between branches and provisional failures. Simplifying independent components does not guarantee the combination passes. |
| [Rubric](../../../prototypes/search-arena/results/simplify/rubric/REPORT.md) | Mood/occasion judgments differ from literal topical matches. Preserve overlay provenance and grade all pooled candidates before declaring a winner. |

## Precise next decisions for the V2 program

1. **Evidence first:** which trait families can be assessed from title metadata, synopsis, reviews, stored tropes or audiovisual evidence? Freeze matched inputs and unknown-state rules before comparing Jev with Qwen/alternatives. Include obscure titles, remakes and season-specific cases to expose memorization and identity errors.
2. **Separate mechanisms:** compare model interpretation, title annotation and ranker changes independently, then measure their interaction. Keep the title catalog and stored embeddings fixed for ranker-only tests; cache the same readings when measuring retrieval changes.
3. **Measurement design:** test binary/nominal facts, coarse ordinal intensity/centrality, explicitness, counts/durations, uncertainty and non-applicability against current 0–10. Measure human agreement, repeated-run stability and judged retrieval—not just arithmetic correlation with Qwen. The historical six/ten-level Jev result is a useful starting arm, not a V2 verdict.
4. **Whole output:** retain and evaluate `essence_text`, `essence_tags`, valid stable `highlight_keys`, advisories and structured companions. Test a composed pipeline if the classifier cannot emit prose. Score factuality, spoiler handling and highlights' representativeness separately from structural validity and token savings.
5. **Turn inventories into evaluation cases:** select a stratified subset of the 256 + 78 scenarios; independently establish candidate title evidence, hard constraints and gold relevance. Do not treat all absence requests as soft penalties. Define unknown coverage, same-character and same-scene semantics explicitly.
6. **Freeze a fresh confirmation set:** historic arena holdouts and openly authored gap scenarios are now development evidence. New blind queries, human calibration and a documented grading rubric are needed before a winner claim.
7. **Cost/time:** report per-title total generation/repair/embedding/index update, per-uncached/cached-query interpretation, local encoding/retrieval, end-to-end p50/p95 and bulk-throughput/concurrency. Include failure reservations, cache assumptions and output coverage. Obtain current prices/routes only when a bounded trial is actually authorized and prepared.
8. **Prototype decision:** does structured concept/role/polarity/exposure enrichment solve concrete failures (e.g. aliens exclusions or monochrome chase scenes) beyond richer prose alone? Compare fixed schema, sparse concepts and evidence-text retrieval with the same title/query judgments before expanding every vector.
