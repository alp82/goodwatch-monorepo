## Question

Which trait families need presence, coarse ordinal levels, 0–10 strength, categories, sparse concepts, quantities or scoped relations, and how will the experiment compare them fairly?

Resolve this as **grilling / HITL**. Use grilling and domain-modeling.

## Evidence to load

Start with [Fingerprint and discovery evidence](https://github.com/alp82/goodwatch-monorepo/blob/planning/fingerprint-discovery-v2-20261019/docs/design/fingerprint-v2/wayfinder/evidence-index.md). Load the 547-attribute definitions, both gap-audit proposal stages, historical Jev six/ten-level/presence-gating results, and the current 74-score snapshot/taste/display dependencies.

## Discussion scope

Keep grilling bounded: ask at most three consequential questions in an initial round, with recommended defaults. Ask a followup only if an answer blocks the next benchmark/prototype or materially changes cost, quality, or scope. Use provisional defaults for reversible details; defer refinements until results reveal a need. Stop once the next experiment can run responsibly. Do not require an exhaustive taxonomy, final architecture, or every attribute decision before a first useful comparison.

## Resolution criteria

Decide candidates for intensity, centrality, frequency, genre membership, quality, suitability, factual presence, quantities/durations, and relation/outcome data. Compare the existing 0–10 contract (11 possible integer values) with explicitly specified smaller ladders; the historical Jev l10 arm had ten native levels remapped to 0–10 and is not identical. Keep class probability/confidence separate from trait strength unless calibrated. Preserve unknown, not-applicable and not-assessed states; zero is not missing. Test peak severity versus exposure, incidental versus central content, descriptive presence versus quality, and role/scene binding. Define how mixed scales reach vectors, filters, display areas and explanations without silently flattening all information into one number.
