## Question

Which complete-output pipeline produces useful essence, tags, highlights and companion data most economically without losing factuality, coverage or display/search value?

Resolve this as **prototype / HITL**. Use prototype.

## Evidence to load

Start with [Fingerprint and discovery evidence](https://github.com/alp82/goodwatch-monorepo/blob/planning/fingerprint-discovery-v2-20261019/docs/design/fingerprint-v2/wayfinder/evidence-index.md). Use existing essence/trope inventories, human-reviewed Qwen full outputs, highlight followup and text-retrieval ablation evidence. Any new paid runs require the approved envelope and this ticket protocol.

## Resolution criteria

Compare only the agreed candidate producers and equivalent output requirements. Measure unsupported claims and spoilers, tag/concept coverage, highlight validity and defining relevance, prose distinctiveness, advisory/source coverage and version/freshness behavior. Account for cached/uncached evidence creation, repairs, local compute, embeddings/index update and any extra generative calls. Derived top numeric scores are a candidate for highlights, not assumed correct for booleans/categories or distinctive importance. Show real title-page/search/Explorer examples so token savings can be judged against usefulness.

## Asset or decision record

A small full-output comparison, consumer examples, a per-component cost/time ledger, and human review of generation versus derivation/reuse tradeoffs.

Record the answer in a resolution comment and link its assets. Close only when the stated decision or prerequisite is complete. Add a named context pointer to the parent map; do not copy full conclusions into the map body.
