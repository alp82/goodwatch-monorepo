## Question

Which current and proposed title-analysis outputs should be generated, extracted from trusted evidence, derived deterministically, reused, replaced or removed?

Resolve this as **grilling / HITL**. Use grilling and domain-modeling.

## Evidence to load

Start with [Fingerprint and discovery evidence](https://github.com/alp82/goodwatch-monorepo/blob/planning/fingerprint-discovery-v2-20261019/docs/design/fingerprint-v2/wayfinder/evidence-index.md). Load architecture-impact.md, current DNAAnalysis and synchronization fields, hybrid-search evidence, invalid-highlight followup, and the compact draft omissions documented by every gap audit.

## Discussion scope

Keep grilling bounded: ask at most three consequential questions in an initial round, with recommended defaults. Ask a followup only if an answer blocks the next benchmark/prototype or materially changes cost, quality, or scope. Use provisional defaults for reversible details; defer refinements until results reveal a need. Stop once the next experiment can run responsibly. Do not require an exhaustive taxonomy, final architecture, or every attribute decision before a first useful comparison.

## Resolution criteria

Account explicitly for essence_text, essence_tags, highlight_keys, production/anime facts, advisories, audience/viewing contexts, world/culture/holiday/representation annotations, factual catalog joins, quality/reception, and provenance. Decide which producers to compare: one generative pass, classifier plus prose/enrichment generator, selected escalation, retrieval-derived text, deterministic highlights, or cached reuse. Evaluate factuality, distinctiveness, spoiler handling and display usefulness as well as length/validity. A classifier's scores-only result is not equivalent to Qwen's whole output. Trace every proposed removal/replacement through text search/embeddings, filters, Explorer, related titles, person pages, Taste, living room and external/API consumers.

## Asset or decision record

An output-by-output consumer and ownership matrix, with proposed producer strategies, freshness/scope rules and experiment metrics.

Record the answer in a resolution comment and link its assets. Close only when the stated decision or prerequisite is complete. Add a named context pointer to the parent map; do not copy full conclusions into the map body.
