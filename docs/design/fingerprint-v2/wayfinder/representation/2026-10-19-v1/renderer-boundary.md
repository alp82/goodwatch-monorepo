# Neutral renderer and raw/canonical boundary

Q11 remains develop_ordinal_plus_facts. The13-slot subset is unchanged. This is a candidate contract correction, not a chosen provider/arm or executable run.

## Smallest meaningful frozen bank

Default to **one neutral disclosed input bundle per relevant field/scope** when it suffices; attach that bundle deterministically. This identifies the supplied input, not a model-selected entailment citation. Preserve a genuinely distinct source conflict or explicit unverified-knowledge path when the task needs it. Six profiles is an upper bound, not a target. With one bundle and no attribution choice, the native value/state inventory is126 options over13 questions;83/question and431 total remain worst-case six-profile bounds, not a token, work, price or request guarantee.

Build the model-visible bank only from the **disclosed input packet**, before outputs, under a fixed policy. Neutral opaque IDs may identify source bundles, source IDs/classes and claim scopes. Raw source text may contain its own explicit negation/modality. The same input contract applies to generation and classification. Prune only type/scope-incompatible tuples; never prune an answer because a hidden referee knows it is false.

The canonical screen schema describes validator/assembly custody, **not a prompt to copy wholesale**. Keep hidden expected values, referee truth, negative_fields, adjudicated binding/conflict, independent-verification decisions and safety eligibility out of model-visible option descriptions and labels. Multiple canonical adjudication records for the same disclosed bundle must not become revealing options such as “verified absence” versus “wrong claim.” Neutral bundle availability and any model-selected attribution remain distinct from later source-support adjudication.

If human-verified claim annotations are deliberately disclosed as input, identify and cost that assistance. Its estimand is performance with curated assertions, not raw-source extraction. For A/B evidence comparisons, a rich packet may create new neutral attribution availability. The combined text/profile-availability intervention is part of enrichment; it is not a text-only contrast with identical tasks. B/C must hold the same rich input and neutral-bank policy fixed.

## Frozen assembly and identity

The standalone CLI checks JSON shape only. validate() additionally checks internal declared metadata. Neither mode establishes custody or source truth. Executable assemble() requires the frozen context and run manifest. It freezes primary_scope_ref, scopes, source/profile banks, field targets and coverage manifests; checks their context hash; binds every scope to the manifest work; and takes producer/model/prompt/source/bank/rubric/cell provenance from the manifest. A producer owns the assessment outcomes, not those identity/custody fields. Non-owned producer metadata is retained as an error, not trusted or silently substituted.

Resolved coverage means a matching frozen full source and a matching registered manifest for the exact scope and denominator. An arbitrary string or a profile flag is insufficient. This bounded adapter implements no partial-source aggregation; an aggregation proposal needs a separately resolved coverage construction before admission. Metadata validation is not independent verification of the referenced material: the source preparer remains responsible for its actual correctness.

## Raw predictions are not censored

Persist the raw producer outcomes, native readouts, selected labels and validation failures before any canonical decision. assemble() returns the original raw output/receipt even if canonical is withheld. Score the knowledge diagnostic against those raw predictions and sealed references, including unsupported false predictions. Canonical withholding cannot turn an error into an abstention success, erase negative predictions, or hide a changed identity. Never silently coerce a failed prediction into zero, false, unknown or a repaired success. Keep attempted/valid/accepted denominators distinct.

Joint value/bundle options split probability mass across bundles. A single joint-option probability is **not calibrated confidence in the value**. Keep raw distributions, selected outcome and any explicitly defined per-value aggregation separate. An expectedScore remains fractional native data; no silent rounding. A native-Score runtime incompatible with this discrete adapter is **not admitted to this contract**, not a quality loser. Later adapter investigation requires an explicit manifest extension and contributes no calls or results now.

The separate48-request A/B/C recommendation remains **unapproved**. It contains no extra masked-identity or factual-probe calls. No unused request capacity becomes autonomous diagnostic capacity. Complete pipeline routing, exact input/output/work bounds, remaining reservations and approval are still prerequisites; no new human arm choice is recorded here.
