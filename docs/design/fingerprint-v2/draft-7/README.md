# Fingerprint V2: vector + attributes

**Current design: 2.0.0-draft.7.** Fingerprint is the umbrella for the **vector** (general resemblance) and **attributes** (specific characteristics). This revision adds the approved color, time-setting, character, group, atmosphere and advisory distinctions.

The **274 vector dimensions, order, definitions and rubrics are unchanged** from draft.6; projection identity remains `similarity-v2.2`. All 605 prior numeric definitions remain unchanged. Added information stays in attributes. No taste weights, query planner, entity graph or production migration is implemented.

Readable values describe allowed types and definitions, not predictions for any title. Attributes comprise **344 targeted scores + 171 presence flags + 60 facets/facts + 110 advisory leaves** (22 topics × five details). The 60 facets/facts are 49 multi-select categories, six booleans, three scalar presence states and two nullable calendar-year integers. All declared keys are required. Title/scope/version envelopes are outside these counts.

## Additions

Thirteen targeted 0–10 scores and twenty facets/facts were added. The existing protagonist-traits vocabulary also gains `adult`, which can overlap `older_adult`; age is established from the work, not the performer. All other prior facet definitions/options are preserved.

## Interpretation boundaries

- **Color:** sustained on-screen appearance, not grading technique, posters or isolated props. Existing warmth, contrast and palette-intensity scores remain available.
- **Time:** depicted versus predominant eras/decades are separate. Main periods must occur in the corresponding depicted sets. Decades cover 1800s–2190s; other settings use eras/year bounds. Signed calendar years use -1 for 1 BCE, 1 for 1 CE, no year zero. Unknown boundaries stay null, rather than invented dates from a broad era. A range does not imply every intervening year appears. Brief flashbacks do not set these bounds.
- **Place and atmosphere:** depicted regions are broad story geography, not production locations or precise countries. Rain can be scenic without being an obstacle; humidity requires its own cues. Old buildings need not be decaying, haunted or gothic. Audible natural sources are distinct from visible scenery.
- **People and groups:** motivations/behavior/arc facets are scoped to protagonists or co-protagonists. Independent fields still do not bind to the same person, relationship, event or group. A female co-lead and a ruthless male co-lead can produce both tags. No linked character records are introduced. Militant, ideological, secret and coercive are distinct properties.
- **Relationships:** friendship care, friction, repair attempts and unresolved strain can coexist. Overall ending closure does not establish resolution of each bond. A romance can be secret without being illicit or socially condemned.
- **Horror:** sustained dread, startles, occult ritual, isolation, monsters and supernatural hunting are independent. Do not infer occult activity from unfamiliar religious observance, nor hunting from encountering a creature. Jump-scare frequency is a recurrence score, not an invented count or artistic-quality judgment.
- **Animal harm:** harm-type selections are stored at `/facets/advisory_details/animal_harm_types` and linked by validation to `/advisories/animal_harm/presence`. Natural death is not deliberate cruelty. Unknown parent presence requires null types; assessed absence requires []; present allows supported types or null. These remain model assessments, not verified exclusion guarantees.

Categorical facets allow overlapping unique choices. `null` is unknown, `[]` is assessed with no listed choice; neither substitutes for the other. Numeric unknowns are not zero. Present with zero narrative centrality remains permitted. Vector publication still requires all numeric dimensions; attributes may retain unknowns. Quality ratings remain interpretive and are not factual proof of quality.

## Generation, migration and checks

Use [vector prompt](VECTOR-PROMPT.md) + [vector definitions](vector.definition.json), separately from [attributes prompt](ATTRIBUTES-PROMPT.md) + [attributes definitions](attributes.definition.json). The two-request design is retained. This change has not measured prompt cost, latency or model accuracy.

[Field catalog](field-catalog.json) supplies stable IDs, exact JSON pointers, types and definitions. [Mapping](mapping.json) retains vector ordering. [Schema overview](schema-overview.md) lists every group. Calendar facts have `calendar_year` kind, never score dimensions. Existing catalog facts and optional prose remain under the [ownership boundary](catalog-ownership.json).

[Migration](migration.json) lists exact additions and the adult vocabulary extension. Preserve historical raw outputs. An explicit migration can retain same-scope existing values and mark new fields null until assessed; it must not derive values from correlated fields or fill gaps with zeros/empty lists. No migration is automatically applied. Previous drafts are unchanged.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 build.py
PYTHONDONTWRITEBYTECODE=1 python3 checks.py
PYTHONDONTWRITEBYTECODE=1 python3 validate.py examples/vector.synthetic.json --attributes examples/attributes.synthetic.json
```

Use `--expected-identity controller-identity.json` for actual intake. `--response` allows inspection of incomplete vector responses. `--export-vector NEW_FILE.json` requires a complete vector and refuses overwrite. [Examples](examples/) are synthetic fixtures only. [Verification](verification.json) records offline checks and source preservation; no inference or deployment occurred.
