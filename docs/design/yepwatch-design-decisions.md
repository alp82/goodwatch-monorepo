# YepWatch design decisions

This file is the backlog of open design decisions and design cleanup for `yepwatch-app`. `yepwatch-app/DESIGN.md` records the system as it is and points here wherever the app disagrees with itself. File paths are relative to `yepwatch-app/src/` unless they start with another folder.

The findings come from a survey on November 18, 2026. Screens were captured on the local end-to-end stack (`e2e/stack/up.mjs`, fixtures only, nothing written to production) at 390 × 844 and 1440 × 900, and the code was read on `origin/main`. Native-only screens (the startup cover and intro film on iOS and Android, Taste mode's full-screen layer) and a few states (tiebreak, cheer, the availability re-check, the leave confirmation, the "Reconnecting…" line) were read from code only.

## How the open decisions get made

The same process as `docs/design/webapp-design-decisions.md`: one `/prototype` session per decision, rendering every affected screen under each option side by side with today's look, on a phone and in a desktop browser, before the owner picks. Record the pick here, update `DESIGN.md`, and turn the follow-up into GitHub issues.

## Family decisions

These affect GoodWatch on the web and YepWatch together.

### F1: Amber value

Status: open.

YepWatch uses `#fbbf24` (Tailwind v3 amber-400). GoodWatch on the web uses Tailwind v4's `amber-400`, `oklch(82.8% 0.189 84.429)`, which is a more saturated, slightly more orange yellow. The web's Open Graph cards and `start.css` also use `#fbbf24`. The two apps' "same" amber differs visibly side by side, for example on the YepWatch share cards that the web app renders.

Options to prototype: one shared amber value for the family; keep each app's value.

Design diff should show: the YepWatch start page, the GoodWatch start page, both apps' share cards, and both wordmarks side by side.

### F2: Fonts

Status: open.

YepWatch sets everything in Gabarito Regular and Bold. GoodWatch on the web uses Gabarito (up to weight 900) for the brand and some page titles and the system sans for everything else (web open decision D3).

Options to prototype: keep each app's approach; align the web's body text to Gabarito; align YepWatch's data and small text to the system font.

## Open decisions

### Y1: Control corner radius

Status: open.

The approved shape scale is `R = { stamp: 4, control: 10, card: 14 }` (`features/shell/tokens.ts:2`). Buttons and fields hardcode 12 instead of `R.control` in about 42 places (for example `features/room/ui.tsx:126`, `features/home/start-parts.tsx:164`, `features/room/panels.tsx:134`). `R` tokens are used only about 26 times in the room flow. Raw literals also include 10 (15), 14 (10), 8 (12), and 9, 6, 5, 3, 2, 16, 21.

Options to prototype: change `R.control` to 12; move buttons and fields to 10; add a separate `button` radius of 12.

Design diff should show: setup, the join page, the voting deck bar, Matches, Tonight, a sheet, and the start page.

### Y2: Reds

Status: open.

About 22 reds are in use. The main ones: `#ef4444` (`glow.red`, redeclared in `glow/EdgeGlow.tsx:17`), `#f87171` (Nope and Leave: `room/Voting.tsx:106,111`, `room/Sheets.tsx:183-190`, `room/YourYeps.tsx:104`), `#fca5a5` (error text: `room/SetupConsole.tsx:214`, `rooms/NewRoom.tsx:107`, `room/MoodComposer.tsx:133`, `room/panels.tsx:54`, `legal/DeleteAccount.tsx:99`), `#ffb2ad` (`colors.danger`), `#dc2626` (trailer play disc), and `#7f1d1d` (vote looks).

Options to prototype: one red token with a light text variant; separate tokens for Nope (a game color) and errors (a status color).

Design diff should show: the Nope key and stamps, Leave, every error message, and the trailer chip.

### Y3: Icons

Status: open.

Six hand-rolled SVG sets: the `glow` `Icon` (14 names, stroke 2, about 48 uses), `HeroIcon` with Heroicons paths (stroke 1.5, 4 uses: Movies and Shows), two `Glyph` components (`room/ui.tsx` and `home/start-parts.tsx:28`), taste `Heart` and `AnswerIcon`, `marks.tsx` (`GoodWatchG`, `StoreLogo`), and `Chevron` and `Plus` in `shell/Header.tsx:64-68`, plus a text "↗" (`room/Poster.tsx:116,133`, `home/install.tsx:57`).

Options to prototype: everything in the `glow` `Icon` set; adopt Heroicons, shared with the web app.

### Y4: Legal and support pages on the web

Status: open.

In the app, terms, privacy, and support use `legal/LegalPage.tsx` (Gabarito, Bold 32 titles, soft unlinked text). On the web, `/terms`, `/privacy`, and `/support` are static HTML generated by `scripts/build-store-assets.ts:17` (system-ui 17px, line height 1.65, h1 36px, underlined amber links). Web visitors never see the in-app version.

Options to prototype: generate the static pages in the app's look; keep the plain reading style for both.

### Y5: Detail and trailer controls on the poster

Status: open.

On phones the voting card shows an amber "Details ↗" chip and a white trailer chip with a red play disc (`room/Poster.tsx:105-135`). On desktop the same controls are outlined, muted chips (`room/Voting.tsx:120`).

Options to prototype: the phone look everywhere; the desktop look everywhere; keep the difference.

## Cleanup: inconsistencies with a likely winner

Confirm the winner before fixing, and fix each as a separate GitHub issue.

- **Legacy token set:** `colors` and `Page`, `Panel`, `Button`, `Field`, `Notice` in `components/ui.tsx` reach users only through `app/preview.tsx` and `app/auth/callback.tsx` (and old screens under `features/*.tsx` reachable only from `/preview`). Winner: `glow` and `warm`. Move `useReducedMotion` and `ActivityDot` out before removing the rest.
- **Hardcoded token values:** 523 color literals (266 distinct) in 70 files. `#fbbf24` is written out 23 times instead of `glow.amber`, `#070707` 16 times instead of `glow.bg`, `#fafafa` 10 times instead of `glow.ink`, and `#1a1610` instead of `warm.well` (`glow/moments.tsx:32`).
- **Amber ink:** five values for text on amber: `#201400` (`warm.ink`, winner), `#141008` (face initials), `#1c1404` (`colors.amberInk`), `#141414` (web invite link), `#19160e`.
- **Near-black duplicates:** `#0d0d0d` (7, mostly `room/Decide.tsx`), `#151515`, `#141414`, `#111`, `#2a2a2a`, `#0f0f0f`, `#101010`; and the note background `#201c13` declared twice (`room/ui.tsx:166`, `shell/floating-note.tsx:64`).
- **Panels:** `#131313` (`glow.panel`), `#141210` (`warm.panel`, winner), `#171717` (`colors.panel`), `#1c1915`, `#242424`, `#262626`.
- **Grays:** `#a3a3a3` (`glow.muted`, winner), `#b6b6b6`, `#9d9d9d`, `#999`, `#888`.
- **Docks:** footer dock `rgba(10,9,8,0.9)` (`room/Frame.tsx:150`) vs `warm.bar` at 0.86 (winner).
- **Fields:** three looks: join and name fields (winner: `warm.faint`, 12px corners, strong line, amber on focus), delete-account (`legal/DeleteAccount.tsx:94`, no fill, 10px corners), legacy `Field` (`#0f0f0f`, `#595959` border, `#999` placeholder).
- **Switches:** room `Switch` 48 × 28 (`room/ui.tsx:174`, winner) vs the Ideas card `SwitchLook` 40 × 24 (`room/SetupConsole.tsx:329`).
- **Primary button re-implementations:** Tonight's Watch link (`room/Tonight.tsx:91`), the join page Join (`room/panels.tsx:134`), and the web "Open in YepWatch" link (`InviteAppLink.web.tsx:8`). Winner: the shared `Button`.
- **Close buttons:** sheet Close with 10px corners vs the popover's round Close (`room/invite.tsx:236`).
- **Links:** bold amber without underline (`TextLink`, winner) vs underlined amber on the join page.
- **Page headings:** legal 32, delete-account 30, "Join the couch" 40 or 56, legacy `Heading` 34.
- **Type sizes:** only `T = { hero: 40, title: 28, body: 16, small: 13 }` is named, but sizes 11, 12, 14, 15, 17, 18, 20, and 22 are each used several times.
- **Name collision:** `room/Voting.tsx:139` defines its own full-screen `Sheet`, unrelated to `shell/Sheet`.
- **Wording:** "couch" in the app vs "room" on the invite card ("Join the room") and in the legal copy.

## Bugs

- Contrast: the "Code or link" placeholder (`warm.placeholder`, 2.91:1), disabled amber buttons at 42% opacity (2.94:1), "Start again" on Tonight reads as text rather than a control, and the disabled secondary "Watch" is very dim.
- No `+not-found` route: unknown URLs show Expo Router's default "Unmatched Route" page in the system font with blue links.
- `fontWeight: '600'` on Gabarito text (`Explainer.tsx:53`), which has no 600 weight loaded.

## Dead code

- `home/styles.ts` (`homeCss`): never imported.
- The old screens under `features/*.tsx` (Lobby, Shortlist, Decision, Voting) reachable only from `/preview`.

## Separate visual systems

- **Share cards:** 1200 × 630 invite and link cards rendered by `goodwatch-webapp/app/server/yepwatch/link-cards.ts`, with red NOPE and amber YEP side bars around the icon.
- **App icon and splash:** `assets/icon.svg` (a gold-gradient card with a Y on `#141414`), Android adaptive icon background `#141414`, and a 44px Y splash (`app.json:39-43`).
- **Intro film:** plays in a WebView on native, or as a still under Reduce Motion.
- **Cheer:** popcorn colors (cream `#fff6dc`, butter `#fbd36b`).
