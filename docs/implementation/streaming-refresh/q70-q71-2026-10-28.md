## Proposed fix — local only

Commit **`814cedabd`**, [complete source/test diff](q70-q71-2026-10-28/proposed-fix.patch):

```diff
-    if any(not re.fullmatch(r'[A-Z]{2}_[1-9][0-9]*', scope) or type(at) is not int or at <= 0
+    if any(not re.fullmatch(r'[A-Z]{2}_[1-9][0-9]*', scope)
+           or not isinstance(at, int) or isinstance(at, bool) or at <= 0
```

Accept integer subclasses while still rejecting booleans, nonintegers and nonpositive timestamps. Preserve the original observation time, hashes, scopes, leases and pending work. No data rewrite, relaxed identity validation or production repair.
