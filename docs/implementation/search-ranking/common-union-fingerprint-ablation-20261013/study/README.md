# Prepared common-union fingerprint study

This local public-data study is prepared and has not run. It uses the 101 English, nonreference captures with existing cached query vectors, the pinned 20261012T041504Z index, and the separately acquired current catalog raw fingerprint matrix. It performs no embedding, JeV, application search, network request, or production write.

Membership is the original pinned-index filter mask intersected with the mandatory fingerprint validity bitmap. It does not silently substitute current catalog votes or apply a new current vote floor. The acquired raw matrix has 42,933 valid rows and one missing row. The bound catalog drift ledger records 2,772 vote differences and 29 current votes below 2,000; these observations preclude historical fingerprint snapshot or current eligibility parity claims.

For each query, the actual authenticated 927 `readingFields` derivative reconstructs its raw signed 74-component vector in the source fingerprint key order from the original public capture. It uses `nativeOnly=false`, as the prepared-input derivative did. Only English captures enter this study. Title fingerprints remain unnormalized raw integer scores. The normalized sidecar is not a scoring input.

The common candidate universe is the union of the filtered dense cosine top 500 and raw fingerprint Dot top 500. Both common-union variants use exactly those rows and the same population z statistics. The control uses original dense, max-cosine negation, label-negation and prior weights. The fingerprint variant adds only the original `0.48 * z(rawDot)` term. No weight is tuned against the grades. Stable ties use pinned index row order. A separate dense-pool control changes the candidate universe and its normalization population, so that comparison is not an isolated fingerprint-weight effect.

The output retains all candidate pool IDs separately from top-100 ranked lists. The evaluator uses the existing #145 graded metric functions verbatim through their authenticated AST, existing grades and query cohorts, and the pinned index alternate-cut pairs. It reports NDCG@10, good@10, bad@5, unjudged@10, condensed NDCG, anchors, historical-list overlap where available, and explicit judged-pair candidate coverage. Its coverage denominator includes judged titles outside the current eligible/common-valid mask; it is catalog judged-pair coverage, not eligible recall. Unjudged titles are not evidence of irrelevance. Historical lists are not current-build final-rank parity.

Missing hybrid signals remain explicit: BM25, facets, coverage, reference/profile signals, final title blending/cut folding and personalization. This is a signal ablation and quality feasibility measurement, not a faithful full production rank replay, capacity result, latency benchmark, acceptance result, or new quality threshold.

Local checks: six synthetic scoring fixtures pass, two evaluator fixtures cover movie/show expected-title namespace/rank/missing identity and three hand-calculated/real-cut metric checks, and Node syntax validation passes. Seven title-lookup guards are reported separately using the original queries.json anchors.must media_type/tmdb_id attribution; they receive no invented relevance grades. These checks have not executed the actual 101-query study. After root source review, the proposed commands are `node run.mjs` and `python3 -B evaluate.py` from this directory. Both refuse existing output files. The runner authenticates bound inputs before importing extracted source helpers; no app or service modules are invoked. Source and input bindings are frozen separately in `study-source-manifest.json`.
