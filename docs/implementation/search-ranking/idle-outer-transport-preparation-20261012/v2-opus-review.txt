## Mandatory blockers

**N1. Evidence (B4 residual): `expected_identities=None` silently disables binding** (`idle_transport.py:66`, `:83`, `:109`, `:114`, `:127`)
- The keyword is required but its value is not checked, so `stage_reviewed(..., expected_identities=None)` creates an unbound `reviewed-preparation` stage as root.
- That call takes the unguarded `read_bytes` branch and skips the comparison.
- **Fix:** in `stage_reviewed`, immediately after the euid check, raise `transport_expected_code_changed` unless `expected_identities` is a dict with exactly the four keys.
- **Test:** patch `geteuid` to 0 and call `stage_reviewed(path, {}, {}, expected_identities=None)`. Expect that reason and `path` absent.

**N2. Evidence: hierarchy-root "not-applicable" is asserted, not observed** (`:314-340`, `:379`)
- `hierarchy_root` proves only that a cgroup2 mount with root `/` and a matching device sits at the path.
- A cgroup-namespace root or a container mount satisfies that while `memory.max`, `memory.high` and `cpu.max` exist there and may be capped.
- The loop then skips the root unconditionally, which is weaker than the inner `idle_trial._sample` (`idle_trial.py:134`), which reads those files when present.
- **Fix:** in `hierarchy_root`, require all three files to be absent (`lstat` raising `FileNotFoundError`), otherwise fail, and record `controllerFilesAbsent: True` in the proof.
- **Test:** the existing fixture plus `groups/memory.max` containing `1024`. Expect `transport_source_fence_failed`; today it passes.

**N3. Coverage: the PID-fd acquisition-failure claims are not red-capable** (`test_idle_transport.py:401-415`, code `:492-501`)
- **Non-invocation is not proven.** The test asserts `inner.jsonl` is absent, but the unprivileged real entry never creates a journal even when invoked.
  - Add assertions that `entry-result.json` and `cli-birth.json` are absent, and that `cliExitCode == 4` when `cliExited`.
- **The "exit cannot be proved" branch has zero execution.** That is the case where `status` stays `None` after the bounded reap.
  - Add a stand-in that sleeps 0.3 s before reading GO, run `_execute` with `release_seconds=.05`, and patch `pidfd_send_signal` to raise.
  - Expect `cliExited` false, `cliExitCode` null, the fixed reason and a durable `outer-result.json`. Reap the finite stand-in afterwards.
- **The real operation-SHA check at `:182` is untested.** `test:362` patches `_verify_stage`, so it only exercises the redundant check at `:409`.
  - Add `_verify_stage(operation, 'unprivileged-refusal-fixture', 'f'*64)` expecting `transport_operation_changed`, plus the correct hash succeeding.
- **The staging-identity test fails on shape, not identity.** `test:618` passes a one-key dict.
  - Use the four correct identities with one field altered, plus a positive case with all four correct.

## Non-blocking

The entry accepts root with `reviewed-preparation` (`idle_entry.py:56`). Optional one-line hardening: have the entry refuse euid 0 until the enabling diff.
- **Exit code 4 is overloaded.** It is both the exception path and the code for `safety_abort`, `release_unproven` and `evidence_failure`. A receipt whose fsync failed can therefore still verify for those non-pass outcomes. Use a distinct code for the wrapper.
