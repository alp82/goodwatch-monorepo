# Local dense and negation signal ablation

This is a local relevance study, not a production result, usable-result PASS, current-final parity check, or new ranking implementation. It used existing public corpus readings, the read-only verified `20261012T041504Z` index (42,934 aligned rows), and locally computed cached query vectors. No application searches, hosts, Jev, model execution, downloads, or history writes occurred in this harness. The separately authorized encoder cache construction is bound as an input.

The successor run includes all 101 English-routed, nonreference queries whose exact synchronous `prepareSearch` texts and reading-dependent negative texts are cached. It excludes 55 reference and 12 non-English-routed cases; two reference cases fall in the latter exclusion count because language is checked first. Corpus class labels and actual routing can differ. Of the included queries, 94 have graded description relevance and seven are title-lookup guardrails assessed separately. There are 21 queries with negated clauses, six with applied eras, and 45 whose stored-reading row mask removes indexed rows. None requires a missing late avoided vector. The preceding 94-query initial-cache run remains intact.

## What was computed

`extract.ts` extracts deployed source commit `927d38b2cca815f02a0b1636ec06f63c24603396`'s actual `quantizedCosines`, population `z`, prior mean-fill function, and fixed weights. Bun removes TypeScript types. The original pure `labelNegation` helper is imported from the previously bound encoder source derivative. Its stem intersection and label-share saturation remain unchanged. There are no invented weights or tuning sweeps.

Each query scans the actual English 768-dimensional int8 matrix using its original per-dimension scales and exact cached preparation text. The dense local top 500 is the only candidate pool; 500 is the existing `MAIN_DEPTH`. Each signal is normalized over those candidates, as the original ranker's scoring rules require. Variants are dense alone; dense plus the existing Goodwatch/vote priors; and that combination plus the existing maximum negative-cosine penalty and negation-label penalty. Label penalties apply only to parsed negated clauses; maximum cosine includes any cached late avoided English phrases. Actual query vectors come from the original encoder worker; index vectors are approximate int8 text projections, **not** exact Qdrant stored-vector scores or ANN candidate parity.

Fingerprint, BM25, facets, coverage units, profiles/reference signals, authoritative result metadata, member taste, and final title blending are uncomputed. Their candidates are also absent. Consequently, z-score normalization differs from the full hybrid candidate union. No claimed final ranking follows from this ablation. Prior statistics and eligibility are from the current index; historical references may use older catalog/ranking inputs.

The masks were generated by the original deployed `readingFields`, `searchFilter`, and `eraRange` against all 168 stored readings. They cover fields represented in the title table, not absent genre/streaming fields or fresh authoritative catalog facts. All 30,300 returned variant rows (101 × 3 × 100) passed their bound mask. Indexed adult/vote eligibility depends on the published build's construction; the title table does not independently expose an adult column for a fresh catalog check.

## Measured relevance

The existing grade scale is 0–3. The original `graded_query6` formulas are executed from the metric source by AST extraction: gain `2^grade − 1`, alternate-cut second occurrence contributes zero, and ideal DCG comes from every graded item. This run supplies the current index's frozen alternate-cut pairs to the existing folding interface instead of rebuilding the historical credits/catalog cut graph. Both candidate and historical reference lists use that same current cut basis here. `bad5` includes judged grade-zero results and duplicate cuts. Unjudged results contribute zero under the existing metric contract and are separately counted; condensed NDCG removes unjudged rows before evaluation and can be optimistic because it hides those positions.

| Variant | Graded queries | NDCG@10 | Good@10 mean | Bad@5 total | Unjudged top-ten slots | Condensed NDCG@10 |
|---|---:|---:|---:|---:|---:|---:|
| Dense | 94 | 0.3273 | 2.8511 | 16 | 598 / 940 | 0.6390 |
| Dense + priors | 94 | 0.3671 | 3.2340 | 24 | 557 / 940 | 0.6774 |
| Dense + negation + priors | 94 | 0.3716 | 3.2979 | 19 | 552 / 940 | 0.6840 |

On the 22 available overlapping holdout-five queries, dense + negation + priors has NDCG@10 0.2905 versus 0.7677 for the historical `combo-safe-v3` list, with mean 6.41 shared titles in the top 20. The ablation has 151 / 220 top-ten slots unjudged; the historical list has none. Its bad-five count is six versus historical fourteen. Thus the large raw NDCG gap does **not** by itself prove relevance inferiority; the historical pool received much more judgment coverage. All 30 historical holdout-five lists are bound, but only 22 survive this study's scope. All twelve historical holdout-four `r6` references are bound, but none survives the nonreference English scope. Current-final overlap remains **unset**, never substituted with historical overlap.

The known judgments do identify concrete failures. For `h5-19` (“harry potter but for adults”), three of the first five results have existing grade zero, including *Harry Potter and the Chamber of Secrets*, *Harry Potter and the Goblet of Fire*, and *Fantastic Beasts: The Crimes of Grindelwald*. For `ho2-09` (“space opera without aliens”), *Ahsoka* and *The Empire Strikes Back* are judged zero in the first five despite applying the existing negation rules. For misspelled `core-04` (“Incepton”), *Incubus* and *7:11 PM* are judged zero. These are existing judgments, not new model grades. Across seven title-lookup guards, the expected title ranks first in two dense-only lists and three lists with priors; this ablation does not implement the authoritative title-lookup blend.

The evidence does not justify a general dense-only substitute for the final ranker. A bounded provisional cohort might still be investigated, but it needs a usefulness decision and better judgment coverage; this run invents neither. Detailed per-query, per-class, per-split, exclusion, guardrail and historical-pair records are in `metrics-v2.json` and `summary-v2.json`.

## Timing and reproducibility limits

Local combined computation (dense and applicable negative scans plus three variant sorts) had median 147.48 ms, p95 order statistic 228.98 ms and maximum 278.36 ms on the retained local machine. These are observations of this one run, not production p95. Index loading, allocation before the timed loop, query encoding, actual reading, catalog, taste, network delivery, full ranking, and host contention are excluded. No end-to-end 1.5-second conclusion is possible.

Known hand-calculated checks cover masked quantized projection, population z-score/constant inputs, prior mean fill, label intersection/saturation, a perfect grade ordering, bad/unjudged separation, and an actual frozen duplicate-cut pair. They are mathematical input/output checks rather than mirrored implementation tests.

Local reproduction, using retained inputs without any model/network call:

```sh
cd <local-study-directory>
node check-primitives.mjs
node run-v2.mjs <exact-prepared-with-filters.json>
python3 evaluate-v2.py
python3 summarize.py
```

`run-v2.mjs` writes a new ranking file with `O_EXCL`; the completed directory cannot be rerun in place. Use a fresh directory containing the exact source files and retained sibling input paths. The evaluation programs presently overwrite only their local derived reports; preserve completed report bytes before reproduction. `study-manifest.json` binds the local harness/results and every reused source, filter, cache, index receipt and historical grade/list input. Grades are the committed `ddb11d2974ff2569851752996ac2d78effb6d623` revision, distinct from the earlier `965bfb99` capture commit. No app source or deployment changed.
