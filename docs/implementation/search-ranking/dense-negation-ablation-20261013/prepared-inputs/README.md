# Pinned index and public query preparation

The original 927 source helpers were exported from Git. The original `loadBuild` reads all ten hash-verified local gzip blobs through an owned HTTP fixture bound to `127.0.0.1` on an ephemeral port. Its requests are restricted to that exact fixture; HTTPS requests and fetch are refused. Only dummy fixture credentials are supplied. No production, Qdrant, profile fetch, Jev call, encoder call, or full rank was executed. The current local build is `20261012T041504Z`, with 42,934 title rows and exact title/mix point-ID order.

`prepare-early.mjs` is a mechanical extraction of the synchronous text block in the original `prepareSearch`: exact spelling, negation, language/model choice and reference resolution. It invokes the original pure helpers. This binds the exact EARLY text list for 168 public captures to this current index. The first cache covers all EARLY texts for 122 captures: 104 of 111 nonreferences and 18 of 57 references. Forty-six captures need 52 distinct model/text vectors, listed explicitly in `missing-early-texts.json`. Reference kinds, intent text and seed/own counts are descriptive metadata, not fetched profiles or resolved intent-vector ranking. Full prepared-search and final-ranking parity are not claimed.

`bind-filters.mjs` additionally invokes the original `readingFields` over the two stored public raw readings, with no new reading calls. All 168 decode successfully. The only unsafe application imports in that module are replaced with refusal-only stubs; metadata and fingerprint-key imports are bound to exported pure 927 sources. Original `searchFilter` and `eraRange` produce masks for the actual indexed title-table order, using the public corpus's `lesserKnown: false` and no external chip filters. The binary has 168 consecutive 42,934-byte masks; each byte is 0 or 1. The manifest binds offsets, hashes and passing counts. These masks represent title-table flags and era, and do not assert unindexed catalog genres or streaming availability. No lesser-known titles absent from this index are added or treated as excluded.

Rows retain decoded flag decisions and the original helper's late English avoided-chip texts, with cache availability stated separately. Initially 94 English nonreference captures have exact EARLY cache coverage, a validated mask and all applicable late avoided texts cached. This is a signal-ablation cohort, not the full production candidate pool or ranker. Additional public vectors are computed only in the separately authorized successor cache directory. No old cache file is modified.

Loader timings are local fixture parsing observations, not production index load or query latency. The two loader invocations read the same pinned local blobs to bind early preparation and filter masks; they did not invoke any encoder. `validation.json` verifies all mask offsets, sizes, contents, hashes and counts. Generated/transpiled source and original source have separate freeze bindings.
