## Non-blocking residuals

1. **Untested fallback (`result_reason`).** The branch that turns `idle_hold_complete` into `idle_guard_failure` for a non-pass row has no test. I believe it is unreachable from the real core, but the doc states the invariant. One synthetic row, `{'outcome':'inconclusive','completionReason':'idle_hold_complete'}`, would cover it.
2. **Subtree check is one-time (`run_reviewed`).** The prefix test runs once, before the writer spawns. `preflight` re-reads `own_group()` into its own `original`, and it and `_run` then recheck equality only. I see no code path that moves the parent, but "verified outside the whole source cgroup subtree" holds only at that first check, and the doc should say so.
3. **New reason strings are unenumerated (`_invoke`).** `idle_journal_release_unproven` and `idle_journal_nongraceful_exit` are in no reason set and are not named in the doc. A consumer validating against `REASONS | LAUNCHER_REASONS` would reject them.
4. **Placement tests do not isolate the core branch.** The same-cgroup test would still pass if `check_source` lost its equality branch, because the launcher line catches the same case. There is also no sibling-prefix case (`/fixture-source-2` must be allowed).
5. **Observer-shutdown and drain reasons are covered by synthetic rows only.** No test carries a real `_run` frame with those fields through `_invoke`.
6. **Superseded V3 sentence.** The V3 section still gives the old precedence order. The V4 section corrects it, so it is not misleading.
7. **Carried from V3.** `journalCreationUnknown` still has no `reason` assertion, and the result still has three shapes.

## Evidence scope
