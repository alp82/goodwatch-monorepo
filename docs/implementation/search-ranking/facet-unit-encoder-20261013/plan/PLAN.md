This is a prepared plan for 132 missing unique `(english, text)` public facet/coverage-unit embeddings. No encoding has run. `plan.json` enumerates every exact text, UTF-8 hash, query ID and role, plus the fixed 101-query English/nonreference cohort, original gates, source/model preflight/old cache bindings and 17 sequential batches of at most eight texts. It excludes references and non-English routing; it does not enlarge the corpus or re-encode existing vectors.

The proposed run uses the original 927 local Worker, existing six pinned local model files, intra-op threads2/inter-op1, one outstanding batch, the original six startup warmups (12 texts), and exactly one pass of 132 missing requested texts. Startup/model hash verification and actual request timings are separate. No download, network, JeV/LLM, application search, global system setting or production action is involved. A fresh absent successor evidence directory is required; the original 168 run, 52 additions, merged cache and completed fingerprint study stay byte-identical. Successful additions would produce a new cache and a derived merged view with bit-exact reuse of prior vectors, never overwrite the old view.

Original gates are preserved: facets need positive text and at least two searched phrases after excluding negated/reference words. Coverage is nonreference, positive text at most five source tokens, at least two source-parsed units, and at least one unit containing a decoded concrete word. Spelling, collocations, stopwords, generic-word exclusions and negation exclusions use the authenticated existing helper. The query/role mapping records phrases that serve both facet and unit roles without encoding them twice.

The downloaded title-aligned `text_en_v1` int8 rows and per-dimension scale support a local quantized dot column for every new query vector, with the same original quantized arithmetic already used in the completed dense study. This preserves input order and the original aggregation formulas, but does NOT prove equivalence to production facet/coverage scores: production round2 obtains exact-query dense columns from Qdrant stored vectors; the downloaded quantized mix vectors are a different representation, and stored-float equality is unproven. This will remain an offline approximation qualification rather than an exact production replay claim.

The original facet term is `0.1 * mean(z(denseFacet_k))`. With these embeddings it can be evaluated on a fixed candidate population using the original mean/z math. Original round1 also unions each facet's top300 into the candidate pool; holding the existing pool fixed isolates a scoring addition, while including those top300 changes retrieval and normalization and must be reported separately.

Original coverage is `0.3 * z(min_k(z(denseUnit_k) + 0.5*z(BM25Unit_k)))`. Each unit has dense top300 retrieval and BM25 sparse top300 maps. Term statistics provide text→ID/IDF query weights, not title-level postings/sparse vectors or those returned top300 maps. These inputs are absent from all ten index blobs. Therefore a dense-only weakest-unit control can be explicitly labeled an incomplete coverage ablation, but cannot masquerade as the original coverage term. Zero-filling unavailable BM25 as valid would be incorrect. The general 0.12 BM25 term is also unavailable for exact replay.

No scoring study is authorized merely by approval of this encoding plan. A next study must separately freeze its fixed candidate universes, approximate dense columns, original untouched weights, optional candidate-retrieval effects and explicit missing BM25 scope. No tuned quality threshold or suppression prediction is implied. Nine of fourteen bad-increase queries have facets/units enabled and all nine need missing embeddings; five have neither enabled. Facets/coverage cannot by themselves account for every current regression.
