# Offline strict fingerprint matrix builder

Prepared locally. The root's actual acquisition is not processed by this builder until root reviews its exact source and fixtures. This module imports only Python stdlib; it makes no network, host, application, model, SQL or Qdrant calls.

The builder authenticates the exact public retrieval plan and reader source by literal SHA-256, the compressed pinned title-table hash and point order, and the exact index-validation receipt hash. It rejects malformed/duplicate JSON keys or nonfinite JSON constants. The entire public stream must have exact EOF with a final newline, exactly one bound header, 42,934 unique aligned row/missing-row frames, and one complete terminal receipt. There are no skipped blank lines, trailing frames or permissive partial-stream modes.

Every row binds to its index row, fixed movie/show namespace and TMDB ID. Batch order and returned-before-missing order are checked. Source omission reasons must be compatible with the public projected values; malformed original nonnumeric components were redacted to null by the reader, so `invalid_component` may legitimately contain null. Valid rows require 74 exact integer scores in 0..10 and a nonzero norm. Missing, partial and invalid rows never become zero-valued valid vectors. All returned/missing/valid/invalid counts, omission counts, current adult/vote drift, per-batch counts, response-byte totals, output-byte accounting and strict terminal time bounds are derived or checked independently. Booleans cannot impersonate numeric counters.

Only after full validation does `main()` create a fresh absent output directory. It emits two aligned 42,934 × 74 little-endian Float32 matrices and one mandatory 42,934-byte UInt8 validity bitmap. Invalid/missing rows contain NaN in both matrices with bitmap 0. The raw matrix retains the exact raw integer scores; it is not normalized. The separate normalized sidecar applies L2 normalization only to valid rows. The original 927 ranker uses `fingerprint_v1_raw` with raw reading weights and Dot scoring; consumers must use the raw matrix for that signal. The normalized sidecar is not a substitute for production raw Dot scores.

The manifest binds shape, byte order, key and point order, validity requirement, source/input hashes and every output-file hash/size. A partial output directory without a valid manifest is not promoted. No overwrite, recovery or partial-publication cleanup is automatic. Public source acquisition and matrix completeness are separate from current eligibility: 29 observed vote-floor drifts, if confirmed by full-stream validation, remain reported metadata; they are not silently removed by the builder. Compared variants must use a separately declared common candidate universe and the same validity bitmap.

Fixtures construct a complete full-size public synthetic stream from the real pinned plan with reversed response order inside each batch. They cover exact source/index authentication, raw/normalized distinction, bitmap/NaN invalid and missing rows, truncated/refused/duplicate/wrong-alignment/wrong-key-order streams, invalid scores and lying omissions, boolean counters, inconsistent byte/batch/drift/time ledgers and source drift. They do not simulate production transactions or prove current catalog/Qdrant equivalence.

The original current catalog extraction is not a historical fingerprint snapshot. A successful matrix build establishes local framing, alignment and numeric validity only, never rank parity, quality acceptance or production latency.
