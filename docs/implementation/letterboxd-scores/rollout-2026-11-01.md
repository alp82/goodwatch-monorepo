# Letterboxd pipeline rollout — 2026-11-01

The owner requested implementation and activation after the
[acquisition research](../../research/letterboxd-data-acquisition.md). This rollout deploys movie score ingestion
and dedicated Crate columns; the webapp score chip and changes to the combined GoodWatch score are outside this change.

## Deployed and enabled

- `f/letterboxd/pages`, `http`, `seed`, `schema`, `crawl` in workspace `goodwatch`.
- Letterboxd fields added to the live `Movie` model and shared schema. Pre-existing live additions were preserved;
  the live shared modules already differed from this checkout. The deployment applied only the task's additions
  to those live modules, rather than overwriting them with older local contents.
- `f/sync/copy/all_ratings` now selects Letterboxd-only changes and publishes/clears the dedicated movie fields.
- The targeted schema initializer added seven columns to `movie`, after its read-only preview.
- Both schedules are enabled, UTC, with `no_flow_overlap=true`: seed daily at 02:40, crawl at :15 and :45 each hour
  with a 25-minute budget and batches of 25. Windmill queued the first crawl for 07:15 UTC and the next daily seed
  for November 2 at 02:40 UTC. Existing source schedules and the existing general score-copy schedule were unchanged.
  The first scheduled crawl started automatically at 07:15:00 UTC, confirmed through the job API.

The initial full seed was launched manually and is still running at the acceptance snapshot: 240,101 movies
queued so far. There are about 708,739 source movie documents with a valid primary IMDb ID; source overrides can
add further candidates. Queue population and crawling are separate jobs. Later full scans are checkpointed after
each committed batch; the deployed seed has a one-hour timeout. The initial job started before the checkpoint
enhancement, so it does not itself write intermediate checkpoints. Its upserts are idempotent.

## Acceptance

The corrected production crawl fetched and published three movies in 13.1 seconds, six HTTP requests, with zero
errors or source blocks. Read-only Crate queries confirmed the source URLs, IDs, scores, normalized values,
exact rating counts and a current source timestamp:

| Movie | TMDB | Letterboxd ID | Score /5 | Normalized | Ratings |
| --- | --- | --- | --- | --- | --- |
| Spirited Away | 129 | `2b4m` | 4.43 | 88.6 | 4,114,621 |
| The Matrix | 603 | `2a1m` | 4.18 | 83.6 | 3,178,866 |
| Inception | 27205 | `1skk` | 4.24 | 84.8 | 4,570,149 |

These are observations at rollout time, not fixed future expectations. Job IDs, deployed script hashes, content
hashes, schedule configurations, source state and the read-only database observations are recorded in
[acceptance-2026-11-01.json](acceptance-2026-11-01.json). No credentials or review text are included.

The first smoke run exposed an overly strict canonical-link assumption: real pages use `og:url`. Three HTTP 200
pages failed the parser, triggering its six-hour unexpected-page pause without publishing data. The parser was
corrected against saved real HTML; a minimal aggregate/identity fixture now covers that markup, including the
IMDb `/maindetails` URL and the production identifier metadata. The confirmed parser-error pause was cleared with
an audit note after the correction. No source challenge or rate-limit response was bypassed.

Offline validation passed: 18 Letterboxd tests, 8 rating-publication tests, 77 existing critic-site tests,
36 copy-since-last-success tests and the Crate model keyword check (140 tests total). Coverage includes exact
counts and scales, identity rejection, unrated versus malformed markup, redirect pacing, shared blocks,
run overlap, cached URLs, score preservation/clearing, resumable seeds, source-only publication and unchanged
aggregate values. `git diff --check` passed for the tracked changes.
