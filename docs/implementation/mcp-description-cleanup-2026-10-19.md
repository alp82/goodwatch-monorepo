# MCP description cleanup, 2026-10-19

Owner decision: remove behavioral and promotional wording before the Claude Connectors Directory submission. All 25 descriptions lose the shared formatting/footer instructions. Inline title/person formatting commands are removed too; search limit/filter and write replay/import wording is factual. Inputs, dispatch, outputs, canonical `url`, ready-made `link`/`stream_link`, `page_url`, and `page_note` are unchanged. Poster UI labels are outside this wording change.

## Current submission and review rules

Read October 19, 2026:

- [Submit a connector](https://claude.com/docs/connectors/building/submission): submissions must meet the directory policy; the portal syncs server tools and requires compliance acknowledgments and tool testing.
- [Connector review checklist](https://claude.com/docs/connectors/building/review-criteria#avoid-prompt-injection-patterns): descriptions must state tool functionality accurately; behavioral or promotional instructions fail review. We retained invocation and parameter guidance directly related to tool functionality.
- [Publish to the directory](https://claude.com/docs/directory/publish): remote servers are submitted as MCP connectors through the developer portal.
- [Software Directory Policy](https://support.claude.com/en/articles/13145358-anthropic-software-directory-policy), sections 2 and 5: compatibility applies broadly to software providing capabilities through natural language; descriptions must match functionality and MCP responses must use tokens proportionately.

The checklist explicitly names tool descriptions, not the initialization `instructions` field. The policy applies to instructional software more broadly, and neither page gives initialization a specific exemption for promotional answer directives. Our interpretation is to apply the same neutral standard there, rather than move the removed commands to initialization. Initialization now explains result fields, taste-match null semantics, runtime, fallback provider links and distinct IDs. This is a conservative application of the policy, not a claim that it expressly bans all initialization hints or guarantees acceptance.
