GoodWatch · Discord cards

Prototype for #738. Pick one variant per card. Every card is built from a Components V2 tree, so the counter and the payload below each mock are what the bot would send. Data: real GoodWatch titles, scores, and availability in Germany, October 23, 2026. Buttons that change the card work here (Yep, Nope, Undo, Another, Rate, menus); other buttons show what they would do. Score badges and service logos inside text are app emojis (Discord custom emojis the app uploads), because Discord text can't be colored.
