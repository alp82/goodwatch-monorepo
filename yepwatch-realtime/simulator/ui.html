How to use this demo
  1. Create a fresh demo. The real app opens as the host; the room cookie stays HttpOnly.
  2. Press Start a round in the actual host app. Simulated guests are already ready.
  3. Use Run automatically, Step all or individual guest controls. Vote independently in the host app.
  4. Finish the host’s round. All required guests must also finish before shortlist appears. A disconnected guest is still required.
  5. Compare the shortlist and propose a title in the host app. Sim guests can accept automatically or you can explicitly accept/decline here. Accept and confirm in the host app.
  6. Try Disagreement, Pause or Disconnect. Reconnect uses a fresh one-use ticket and that guest’s own private HTTP state. Use Recover after an uncertain request.

This finite real-title sample and memory room API are a POC, not production catalog/storage proof. All retained app/API/gateway services remain untouched. Closing this tool only closes its sockets; it never removes a required voter or consents for a disconnected person.
