How this lab works

Rules update while typing. Fingerprint reads run only when you press Run or evaluate the phrase set with reads enabled. Jev reads the real fingerprint vocabulary and asks which existing mood, theme, style and audience filters apply. This is request interpretation, not title fingerprint scoring.

Current semantics apply: values within moods, genres, themes and styles match any; filter groups combine. Age uses the viewing country's rating ladder and also sets content defaults. People includes both cast and crew. Unsupported wording stays in search text.

Opening Discover uses its current catalog, availability and search ranking. This lab does not change production search behavior or saved settings.
