# OLD shutdown admission amendment

The frozen external invocation at head `131cec2913e70e963329197e8f105faffd522a89` refused before the first OLD stop because the shared host admission required more than 5 GiB. This amendment separates a bounded OLD-only graceful shutdown from operations that start a new source or admit a comparison. It does not repeat that invocation or assert runtime success.

`old_shutdown_host()` has a fixed strict floor of 2 GiB and emits `cpu0-old-shutdown-host-admission.v1`, target `old-owned-shutdown`, with `diagnosticComparisonAdmission=false`. Two GiB is an explicit engineering margin for small bounded inspectors and releasing owned anonymous memory; it is not a Linux guarantee. This function has no caller-supplied lower threshold. `host()` retains its original strict 5 GiB floor before NEW creation/start. All CPU0 controller, preflight, turnover and pin resource policies are unchanged.

The OLD path retains the same CPU2-only exception, zero-throttle ancestors, collection shape, physical metadata-client close, exact source/image/config/wrapper/child/birth/entrypoint fences, control and instance locks, prior writer/control census, protected PID exclusions, zero swap, more than 3 GiB disk free and less than 11 GiB owned allocation. The same 20-second child-only graceful stop, no Qdrant KILL fallback, durable clean receipt, nonzero/timeout refusal and no automatic recovery still apply. A clean OLD stop does not authorize NEW creation: full host admission must pass afresh. Failure can leave OLD stopped with no NEW start; that is not a pristine baseline or comparison result.
